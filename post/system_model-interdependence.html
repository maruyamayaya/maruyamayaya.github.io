Interdependent Networks: How One Broken Route Can Trigger a Cascade

发表于2026-08-11|更新于2026-11-12|复杂系统
|总字数:4.7k

Complex Systems · 9/11 · Series index · Notation

Two networks, two ways to fail

Suppose a substation still has an intact line to the rest of the power grid. Can it keep running? If it needs a working controller, knowing the state of the grid is not enough. The controller must have power and a route through the communications network. The power line and the control link do different jobs, and a path made by joining the two kinds of link is of no use to either system.

Consider a duplex, a network with two layers. Let AAA be a power layer and BBB a control layer, each with nnn nodes. A connectivity link provides a route within one layer. A dependency link says that two devices need each other to operate. A multiplex describes several kinds of connection among corresponding entities; dependence is an additional rule about what it takes to function. Here each device has exactly one partner in the other layer. A pair works only while both devices have a route into their own layer’s functioning backbone. This is an idealized rule, not an assumption that any real substation necessarily fails when one particular controller goes offline.

Trace one failure in the diagram. The numbered circles are devices; the two bars stand for intact backbones outside this small patch. Remove power device 1. Its control partner goes offline, cutting control device 2 off from its backbone. Power device 2 now loses its partner even though its own power line is intact. Its loss isolates power device 3, which takes down control device 3. Control device 4 loses its route, and finally power device 4 loses its partner. A single deletion has disabled four pairs. Every step follows one of two rules: lose your route, or lose the partner you require.

In a large random network the backbone is determined by the same rules as everything else. Randomly retain each node of AAA with probability ppp, where 0≤p≤10\le p\le10≤p≤1, and remove the partners of the lost nodes. Then repeatedly remove nodes outside their layer’s giant component and the partners that depend on them. The surviving extensive set is the mutually connected giant component (MCGC): the same set must be connected in each layer through paths that stay within the set. Taking the intersection of the two original giant components only once can leave paths that rely on nodes already removed.

Write μ\muμ for the final number of surviving pairs divided by the original nnn pairs. Initially a pair survives with probability ppp; after the cascade 0≤μ≤p0\le\mu\le p0≤μ≤p. There is only one initial attack. If both layers were independently attacked with retention probabilities pAp_ApA​ and pBp_BpB​, the initial pair retention would instead be pApBp_Ap_BpA​pB​.

What must be true at the far end of a link?

These equations are self-consistent: an edge succeeds if at least one of the edges ahead succeeds under the same rule. The expression for μ\muμ has no edge-arrival test because we selected a device pair directly. Both layers have the same number of functioning devices, yet their edge success probabilities can differ.

The all-zero solution is always present. Which solution is realized if there are several? Start with every branch provisionally successful, x=y=1x=y=1x=y=1, and repeatedly apply the right-hand sides. The update rules are increasing in both inputs, so the first decrease can only be followed by a decrease or equality. This sequence is bounded below by any fixed point and converges to the largest fixed point. That is precisely the solution selected by a process that starts intact and only removes nodes. Written in terms of failure probabilities, the same choice would be the smallest failure solution.

Watching the damage propagate

The same final size can be reached by following the cascade one layer at a time. This reveals a bookkeeping issue: the fraction currently alive is usually not a fresh random sample from a layer it has already passed through.
